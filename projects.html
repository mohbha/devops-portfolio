01 DevOps & Monitoring

Containerized Observability Stack

Problem
Host health problems stay invisible until something breaks. I wanted real-time visibility into kernel-level metrics, with a warning before a host degrades.
Approach
A multi-threaded Python agent polls kernel metrics and serves them through a Flask producer. Prometheus scrapes it, Grafana renders live dashboards, and threshold breaches trigger REST API warnings. Three containers, orchestrated with Docker Compose.
Result
A reproducible monitoring stack that boots with one command: metrics collected, stored as time series, visualised and alerting end to end.

02 AWS Infrastructure

Cloud Portfolio & CI/CD

Problem
A portfolio should be fast, HTTPS-only and almost free, with no server to patch and no bucket exposed to the internet.
Approach
Static files live in a private S3 bucket that only CloudFront can read. A GitHub Actions pipeline runs on every push, syncs changes with a Python/Boto3 script that sets the right MIME types, then refreshes the CDN cache.
Result
Every push goes live automatically: HTTPS, CDN-delivered, no public bucket and no manual uploads.
